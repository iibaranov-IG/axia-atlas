# Axia Atlas — инженерное рабочее место
Axia Atlas объединяет работу инженера радиостанции с сетью Axia Livewire, оборудованием, аудио и документацией в одном Windows-приложении. Версия 0.2.0-rc.1 — кандидат на выпуск. Интерфейс русский и английский, оформление Windows и macOS.

## Рабочее окно
Слева: Сеть, Аудио, Библиотека, Приборы и Сценарии. В центре: страницы приборов, документы, измерения, записи и инструменты. Справа: Виртуальный инженер. Боковые панели скрываются; компактное прослушивание показывается на вкладке Аудио. Переход на другую вкладку не останавливает уже запущенный звук или запись.

## Реализованные возможности
| Раздел | Что делает |
|---|---|
| Сеть | Слушает объявления Livewire на выбранном адаптере, читает сведения поддерживаемых устройств, сохраняет наблюдения и показывает исчезновение объявлений. |
| Приборы | Хранит карточки оборудования, назначение, заметки и адреса управления с портами. Студийные Axia-устройства показываются в Сети; внешние приборы — отдельно. |
| Веб-интерфейсы | Открывает страницы приборов внутри Atlas, поддерживает переходы и HTTP-аутентификацию. |
| Аудио | Показывает включённые источники с номером канала; принимает поддерживаемый стереопоток, отображает уровни и счётчики. |
| Записи | WAV и MP3 с выбором доступных параметров, список записанных файлов и их прослушивание. Громкость прослушивания не изменяет уровень записи. |
| События и состояние | Общая лента событий Atlas и Syslog; история изменений; контроль нескольких потоков; признаки пропусков, тишины и перегрузки. |
| Диагностика | Экспортирует измерения и инженерные сведения; по явному действию добавляет короткую запись. |
| Библиотека | Подбирает доступные ссылки по оборудованию, загружает материалы по запросу, открывает PDF внутри программы, индексирует инструкции для поиска. |
| Карта сигналов | Сопоставляет прочитанные назначения и отдельно сохранённые инженерные связи. Номер канала сам по себе не доказывает физическое подключение. |
| Сценарии | Сохраняет планы переключения, проверяет назначения, требует отдельного разрешения на выполнение и останавливается при ошибке шага. |
| Снимки конфигураций | Хранит доступные сведения и позволяет сравнивать их. Полное восстановление прибора не заявляется. |
| Смены | Локальный график, отпуска, замены и ответы по календарю. |
| Пользователи | Технический директор назначает права. Общий сервер учётных записей и зашифрованные профили паролей приборов доступны нескольким клиентам. |
| Расшифровка | Преобразует локальную запись в текст и субтитры. Файлы распознавания загружаются отдельно после подтверждения. |
| Виртуальный инженер | Использует разрешённый контекст и справочные материалы для рекомендаций; команды оборудованию не выполняет. Требует отдельной локальной службы. |

**ATLAS Broadcast Player — отдельный модуль**, со своим процессом, медиатекой и статусом испытаний. Он не заменяет основной Atlas и не является предметом приёмки основной программы как эфирного плеера.

## Следующие этапы
Матрица совместимости реальных приборов; длительные испытания аудио на физических рабочих станциях; общее хранилище инженерных записей; служба учётных записей; управляемое восстановление конфигурации; проверенное управление прошивками; устойчивые постоянные сценарии аварийного переключения; подписанный установщик и обновления. Логгер и интернет-вещание планируются отдельными модулями.

## Границы готовности
Обнаружение устройства не доказывает наличие звука. Измеренные потери не локализуют причину автоматически. RDP-прослушивание не заменяет проверку физического аудиовыхода. Полная совместимость AES67/PTP не подтверждена.

Публичная сборка не содержит сведения конкретной студии, сотрудников или пароли. Общие учётные записи пока не синхронизируют карточки, карты, сценарии и смены. Доступ к веб-интерфейсу прибора означает доступ к действиям, разрешённым самим прибором.
