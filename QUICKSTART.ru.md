# Axia Atlas — начало работы

Версия 0.2.0-rc.1 для Windows x64. Это кандидат на выпуск для проверки инженерами.

## Запуск

Распакуйте весь ZIP в отдельную папку и откройте **AxiaAtlas.exe**. Папка **_internal** должна остаться рядом с программой. Устанавливать Python не нужно. Цифровая подпись Windows отсутствует.

При первом запуске откроется управление доступом: создайте учётную запись технического директора либо подключитесь к серверу учётных записей вашей организации. Программа не содержит готовых паролей. Первоначальная настройка локальной рабочей области не означает, что устройства сети уже проверены.

Интерфейс сначала открывается на русском. **Вид → Язык** сохраняет выбор русского или английского для следующего запуска. Оформление Windows или macOS меняется отдельно.

## Основная работа

- **Сеть:** выберите нужный сетевой адаптер и нажмите запуск сканирования. Сохранённый прибор не считается доступным до нового наблюдения.
- **Аудио:** выберите источник с номером канала, устройство воспроизведения и запустите прослушивание. Запись WAV/MP3 включается отдельно. Записи доступны в центральной области аудиомонитора.
- **Библиотека:** показывает материалы для найденного оборудования. Документы открываются внутри Atlas. Наличие файла прошивки не означает, что Atlas умеет устанавливать её.
- **Приборы:** карточки внешнего оборудования и его адреса управления, в том числе с портом.
- **Сценарии:** сохраните план, проверьте его и отдельно разрешите выполнение. После открытия программы разрешение выполнения сброшено.
- **Инструменты:** расшифровка файла в текст. При первом использовании программа предложит загрузить файлы распознавания; нужна связь с интернетом. Сама запись обрабатывается локально.
- **Виртуальный инженер:** необязательный помощник. Если локальная служба не настроена, справочники и остальные инженерные функции остаются доступны.

Доступ к веб-интерфейсу прибора разрешает и действия, которые предоставляет сам прибор. Права Atlas не заменяют права внутри его веб-интерфейса.

## Обновление и сохранность данных

Закройте все окна Atlas, распакуйте новую версию в новую папку и откройте её. Не запускайте старую и новую версии одновременно с одной рабочей областью.

Настройки, карточки, пользователи и записи состояния сохраняются в **%LOCALAPPDATA%\\AxiaAtlas**. Архив программы не содержит этот каталог. Перед обновлением сохраните его копию при закрытой программе. Пароли защищены средствами Windows и привязаны к пользователю компьютера: простое копирование базы на другой компьютер не переносит доступ к ним.

Данные сотрудников, студийная карта и справочник конкретной радиостанции не поставляются с публичной сборкой. Существующая студийная карта не перезаписывается демонстрационными сведениями.

## Что ещё требует проверки

Кандидат не заменяет приёмку на вашей рабочей станции и резервном оборудовании. Нужны длительное прослушивание и запись, проверка поддерживаемых моделей, сетевого интерфейса и сценариев вне эфира. Отдельный Broadcast Player также остаётся модулем для контролируемых испытаний.
